# Неделя 11 — качество и безопасность

Продолжаем сервис недель 9–10. Проверка — PR-ревью + мини-собес по Spring.

1. **Урок 1 — unit-тесты.** Mockito для сервисного слоя: минимум
   6 тестов (happy path + ошибки). Без поднятия контекста Spring.
2. **Урок 2 — веб- и интеграционные тесты.** `@WebMvcTest` на контроллер
   (200, 400, 404) и один `@SpringBootTest` + Testcontainers
   (настоящий Postgres в контейнере).
3. **Урок 3 — Security + JWT.** Логин → токен → доступ. Роли USER/ADMIN:
   удалять заявки может только ADMIN. Пароли — только BCrypt.
4. **Урок 4 — логирование и конфиги.** SLF4J: INFO на бизнес-события,
   ERROR с исключением; в логах нет паролей/токенов. Профили
   `dev`/`prod`, секреты — через переменные окружения, не в git.
5. **Урок 5 — код-стайл.** Подключи checkstyle или spotless,
   почини все замечания, добавь прогон в свой CI.

Ориентир по покрытию: 60%+ ключевой логики (сервисы).
Сдача: PR + зелёный CI + мини-собес по Spring (30 минут).
