# Неделя 5 — Git, Maven, JUnit

Код-часть недели: `src/main/java/academy/week05/StringCalculator.java`
(урок 4). Остальные задания — процессные, их проверяет ментор.

## Урок 1 — Git базово

1. Создай СВОЙ репозиторий на GitHub (не этот): любой pet-проект.
2. Сделай минимум 5 осмысленных коммитов (`add` → `commit` → `push`).
3. Добавь `.gitignore` (минимум: `target/`, `.idea/`).

Сдача: ссылка на репозиторий ментору.

## Урок 2 — ветки и Pull Request

1. Создай ветку `feature/readme`, поменяй README, открой PR в `main`.
2. В паре с другим студентом: оба меняете одну и ту же строку в разных
   ветках → устраиваете конфликт → разруливаете merge.
3. С этой недели ЛЮБОЕ изменение — только через PR. Прямые пуши в main
   ментор отклоняет.

Сдача: ссылка на смерженный PR + скрин разрешённого конфликта.

## Урок 3 — Maven

1. Собери свой проект: `mvn package`, найди jar в `target/`.
2. Объясни ментору устно: что такое `groupId/artifactId`, зачем
   `dependencies`, какие фазы у жизненного цикла (`compile → test → package`).

## Урок 4 — JUnit + TDD (автопроверка)

1. Реши `StringCalculator` строго по TDD: сначала СВОЙ тест в своём
   репозитории, потом код.
2. Напиши минимум 8 своих тестов (позитивные, граничные, исключение).
3. Запушь сюда — скрытые тесты CI проверят итоговое поведение.

## Урок 5 — дебаггер

1. Поставь breakpoint внутри своего `StringCalculator.add`.
2. Пройди step over / step into, посмотри значения через Evaluate.
3. Покажи ментору на созвоне. Напоминание: дебаг «принтами»
   с этой недели запрещён на ревью.
