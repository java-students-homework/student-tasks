# Неделя 12 — Docker, Kafka, Redis

Обзорная неделя под командный проект. Проверка — демо ментору:
всё поднимается одной командой.

1. **Урок 1 — Docker.** Dockerfile для сервиса недели 11
   (multi-stage: сборка Maven → лёгкий JRE-образ). Собери и запусти
   контейнер локально.
2. **Урок 2 — docker compose.** `compose.yaml`: app + postgres.
   Конфиг через переменные окружения. `docker compose up` поднимает
   рабочий сервис с миграциями.
3. **Урок 3 — Kafka.** Добавь kafka в compose. При смене статуса заявки
   публикуй событие `order-status-changed` (JSON). Отдельный
   `@KafkaListener` (можно в том же приложении) читает и логирует его.
4. **Урок 4 — Redis.** Добавь redis в compose. Закэшируй
   `GET /orders/{id}` c TTL 60 секунд и покажи в логах, что второй
   запрос в базу не ходит.
5. **Урок 5 — healthcheck и CI.** Подключи actuator
   (`/actuator/health`), пропиши healthcheck в compose. Убедись, что
   твой GitHub Actions гоняет сборку + тесты на каждый PR.

Сдача-демо: `docker compose up` → создать заявку → сменить статус →
в логах событие Kafka → повторный GET из кэша.

Недели 13–15 — командный проект LabPrint, неделя 16 — трудоустройство:
задания там выдаёт ментор, в этом репозитории домашек нет.
